# Git — первый запуск для личного пилота

1. Install **Git for Windows** and sign in to GitHub (Git Credential Manager is recommended).
2. Create an empty **private** repository named `rx2go-ai-qa` on your personal GitHub account.
3. Open **Rx2GO AI QA → Knowledge → Настроить Git**.
4. Paste the repository URL when prompted.
5. Use **Commit knowledge**, then **Synchronize**.

When the team moves to a shared organization later, change `origin` to the organization repository; the Git history and accumulated knowledge remain intact.
